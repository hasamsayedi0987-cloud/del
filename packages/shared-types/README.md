# `@del/shared-types`

تایپ‌های TypeScript مشترک بین تمام اپ‌ها و پکیج‌ها: مدل‌های دامنه (`User`, `Conversation`, `Message`, `CallSession`, ...)، انواع رویدادهای WebSocket و شکل پاسخ‌های API.

**اصل کلیدی:** قراردادها فقط یک‌بار اینجا تعریف می‌شوند و همه کلاینت‌ها + بک‌اند از همان نسخه استفاده می‌کنند تا drift بین سمت‌ها ممکن نباشد.
