# `@del/validation`

اسکیماهای اعتبارسنجی مشترک (Zod) برای ورودی‌های API، پیام‌ها، پروفایل‌ها و تنظیمات. بک‌اند با این اسکیماهها ورودی را در لایه Pipes اعتبارسنجی می‌کند و کلاینت‌ها همان اسکیماهارا برای فرم‌ها به کار می‌برند.

**اصل کلیدی:** اعتبارسنجی هرگز فقط در UI انجام نمی‌شود؛ منبع حقیقت همین پکیج است و سرور آن را اجباری اجرا می‌کند.
