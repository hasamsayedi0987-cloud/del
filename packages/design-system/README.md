# `@del/design-system`

سیستم طراحی «دل»: توکن‌های رنگ/تایپوگرافی/فاصله، کامپوننت‌های پایه (دکمه، ورودی، حباب پیام، آواتار، شیت‌ها) با پشتیبانی کامل از **حالت روشن/تاریک** و **RTL/LTR**.

**اصول:**
- کامپوننت‌ها بدون وابستگی به پلتفرم؛ آداپتورهای بومی برای RN و React DOM
- تایپوگرافی خوانا با فونت Vazirmatn برای فارسی
- وضعیت‌های استاندارد: loading / error / empty / offline
