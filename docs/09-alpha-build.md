# ۰۹ — سند بیلد آلفا (Alpha Build Report)

> **نسخه:** `0.1.0-alpha.1` · **تاریخ:** اکتبر ۲۰۲۵ · **وضعیت:** قابل نصب و تست

---

## ۱) چه چیزی ساخته شد؟

در این مرحله (آغاز فاز ۲)، اسکلت فاز ۱ به یک **برش افقی قابل اجرا (Horizontal Slice)** تبدیل شد؛ یعنی هر سه لایه محصول به‌صورت واقعی کار می‌کنند و خروجی نصب‌پذیر دارند:

| لایه | فناوری | خروجی |
|---|---|---|
| هسته مشترک UI | React 18 + TypeScript + Vite + Zustand | باندل ~۷۱KB gzip |
| اپ اندروید | Capacitor 7 (پوسته Native Android) | `APK امضاشده ۳.۶MB` |
| اپ دسکتاپ | Electron 33 | `ZIP قابل‌حمل ویندوز` + `AppImage لینوکس` |
| سرور | Node + Express + Socket.IO + SQLite | بسته قابل‌حمل `del-server.zip` |

### قابلیت‌های این نسخه

- **ورود با شماره تلفن + کد OTP** (کد آزمایشی: `12345`) و ثبت نام کاربر
- **لیست گفت‌وگوها** با جست‌وجو، پیش‌نمایش پیام، شمارنده پیام خوانده‌نشده
- **صفحه چت ۱:۱** با حباب‌های RTL، جداکننده تاریخ، تیک ارسال/خوانده‌شدن، نشانگر «در حال نوشتن»
- **حالت دمو (آفلاین):** چهار مخاطب نمونه با ربات پاسخ‌گو — بدون سرور هم اپ کاملاً کار می‌کند
- **حالت سرور واقعی:** اتصال REST + WebSocket به سرور دل از صفحه تنظیمات
- **دوزبانه:** فارسی (پیش‌فرض، RTL کامل) و انگلیسی — سوئیچ از تنظیمات
- **تم تیره/روشن** با سیستم طراحی Crystal Blue
- **پروفایل:** ویرایش نام و رنگ آواتار

## ۲) تصمیم فنی این مرحله (ADR — ثبت شفاف)

سند معماری (۰۲) برای فاز تولید **React Native + Expo** را تصویب کرده است. برای بیلد آلفا از **هسته وب مشترک + Capacitor/Electron** استفاده شد:

- **چرا:** تحویل خروجی نصب‌پذیر هم‌زمان برای اندروید/ویندوز/مک/لینوکس با یک کدبیس UI؛ حجم APK فقط ۳.۶MB؛ سیکل بازخورد سریع‌تر برای تأیید طراحی محصول.
- **مسیر فاز بعد:** هسته UI (State/Theme/i18n/API Client) عیناً به RN منتقل می‌شود؛ فقط لایه رندر عوض می‌شود. ویژگی‌های نیازمند Thread بومی (تماس، پوش بومی، E2EE پس‌زمینه) با RN+Expo ساخته می‌شود.
- **مهاجرت:** `packages/api-client` و `packages/design-system` مستقل از پلتفرم نوشته شده‌اند و بدون تغییر در RN کار می‌کنند.

## ۳) فایل‌های خروجی و روش نصب

### 🤖 اندروید — `Del-0.1.0-alpha.1-android.apk`

1. فایل را به گوشی منتقل کنید (کابل/اشتراک‌گذاری).
2. روی فایل بزنید؛ اگر پرسید، «اجازه نصب از منابع ناشناس» را فعال کنید.
3. اپ با نام **«دل»** نصب می‌شود. (اندروید ۶ به بالا، targetSdk 35)
- **امضا:** کلید release اختصاصی `del-release.keystore` (رمز: `DelSecure2026!` — در دسترس تیم نگه‌داری شود و **کامیت نشود**).
- ⚠️ نسخه‌های بعدی باید با همین keystore امضا شوند وگرنه به‌روزرسانی نصب نمی‌شود.

### 🪟 ویندوز — `Del-0.1.0-alpha.1-windows-portable.zip`

1. ZIP را باز (Extract) کنید.
2. `Del.exe` را اجرا کنید — نصب لازم نیست.
- نصاب گرافیکی `setup.exe` به‌صورت خودکار از طریق GitHub Actions ساخته می‌شود (به بخش ۴ ببینید).

### 🍎 مک — از طریق GitHub Actions

بیلد اپ مک (DMG) فقط روی سیستم macOS ممکن است (محدودیت اپل). ورک‌فلو `build-desktop.yml` آماده است:

1. در GitHub به تب **Actions → build-desktop** بروید.
2. **Run workflow** را بزنید (یا تگ `v0.1.1` push کنید).
3. فایل `Del-x.y.z-macos-arm64.dmg` از Artifacts دانلود می‌شود.

### 🐧 لینوکس — `Del-0.1.0-alpha.1-linux-x86_64.AppImage`

`chmod +x` سپس اجرا کنید.

### 🖥 سرور — `del-server-0.1.0-alpha.1.zip`

```bash
unzip del-server-0.1.0-alpha.1.zip -d del-server && cd del-server
node server.js          # یا: docker compose up -d
```

سپس در اپ: **تنظیمات → اتصال به سرور →** `http://<IP-سرور>:3000`

## ۴) بیلد خودکار (CI/CD)

دو ورک‌فلو اضافه شد:

| ورک‌فلو | تریگر | خروجی |
|---|---|---|
| `build-android.yml` | push روی `apps/mobile` یا اجرای دستی | APK |
| `build-desktop.yml` | push تگ `v*` یا اجرای دستی | setup.exe (ویندوز) + DMG (مک) + AppImage + بسته سرور |

## ۵) محدودیت‌های نسخه آلفا (شفاف برای تست‌کنندگان)

- رمزنگاری سرتاسری **پیاده نشده** — مطابق سند ۰۶ تا قبل از E2EE هیچ ادعای امنیتی نمی‌کنیم.
- رسانه (عکس/فایل) هنوز وجود ندارد؛ فاز ۳ با Presigned URL اضافه می‌شود.
- گروه‌ها و تماس‌ها در فازهای ۴ و ۵.
- کد OTP ثابت است؛ اتصال سرور به SMS Gateway در فاز تولید.
- بازیابی گفت‌وگو فقط تا ۶۰ پیام آخر در هر گفت‌وگو در حافظه محلی دستگاه.

## ۶) چک‌لیست تست پیشنهادی

1. نصب APK روی گوشی واقعی → ورود با هر شماره + کد `12345` → گفت‌وگو با مخاطبین دمو.
2. اجرای سرور روی یک لپ‌تاپ → اتصال دو دستگاه (مثلاً گوشی + ویندوز) → چت دوطرفه واقعی.
3. تغییر زبان/تم → بررسی RTL و ظاهر.
4. قطع/وصل سرور → رفتار حالت دمو.
