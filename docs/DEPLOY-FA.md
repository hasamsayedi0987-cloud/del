# دیپلوی سرور دل — همیشه‌روشن و رایگان (بدون کامپیوتر)

سرور API دل روی **Render** (سرویس ابری رایگان) اجرا می‌شود. یک بار تنظیم می‌کنید و برای همیشه روشن می‌ماند — حتی وقتی کامپیوتر شما خاموش است.

## راه‌اندازی در ۳ قدم

1. این لینک را باز کنید:
   **https://render.com/deploy?repo=https://github.com/hasamsayedi0987-cloud/del**
2. با همان حساب **GitHub** خودتان وارد شوید (Sign in with GitHub).
3. فایل `render.yaml` به‌طور خودکار خوانده می‌شود — فقط دکمهٔ **Apply** را بزنید.
   وب‌سرویس `del-messenger-api` + دیتابیس `del-db` ساخته می‌شود (~۵ دقیقه اولین build).

بعد از اتمام، آدرس عمومی سرور: `https://del-messenger-api.onrender.com`

## اتصال اپ موبایل

اپ نسخهٔ **1.3.0 به بعد** به‌صورت پیش‌فرض به همین آدرس وصل می‌شود — هیچ تنظیمی لازم نیست.
اگر آدرس متفاوت شد: در اپ → «تنظیمات پیشرفته» → آدرس سرور جدید را وارد کنید.

## ورود بدون پیامک

تا وقتی SMTP تنظیم نشده، سرور در حالت توسعه است (`AUTH_DEV_MODE=true`) و **کد ورود مستقیم داخل خود اپ نمایش داده می‌شود** — بدون نیاز به پیامک یا ایمیل واقعی.

## ورود واقعی با ایمیل (اختیاری ولی توصیه‌شده)

1. یک App Password بسازید: حساب Gmail → Security → تأیید دومرحله‌ای → App Passwords (رمز ۱۶ رقمی).
2. در داشبورد Render → سرویس `del-messenger-api` → Environment:
   - `SMTP_HOST` = `smtp.gmail.com`
   - `SMTP_PORT` = `587`
   - `SMTP_USER` = آدرس Gmail شما
   - `SMTP_PASS` = همان App Password
   - `SMTP_FROM` = `Del <آدرس-gmail-شما>`
3. Save → سرویس خودکار دوباره deploy می‌شود.
   حالا کد ورود به‌صورت **ایمیل واقعی** برای هر کسی که در اپ ایمیل وارد کند می‌رود.

پیامک (کاوه‌نگار/Twilio) هم پشتیبانی می‌شود — کلیدهای قبلی را به Environment اضافه کنید.

## نکته‌های مهم

- **دیتابیس رایگان Render** هر ۳۰ روز منقضی می‌شود و Render هشدار ایمیل می‌دهد؛ برای ماندگاری دائمی می‌توانید یک Postgres رایگانِ دائمی (مثل Neon یا Supabase — ورود با GitHub) بسازید و فقط `DATABASE_URL` را در Environment جایگزین کنید.
- workflow `keep-api-warm` در همین ریپو هر ۱۰ دقیقه به سرور پینگ می‌دهد تا سرویس رایگان خاموش نشود.
- برای پروداکشن واقعی، `AUTH_DEV_MODE` را `false` کنید (بعد از تنظیم SMTP).
